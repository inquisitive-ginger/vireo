# 002 — Two-Layer Currency Model

**Status:** Decided

**Decision:** Two distinct currencies — XP (pure gamification, never
converts) and Family Dollars (F$, earnable and redeemable, can convert
to real money).

**Why:** Separates game feel from financial lesson. Lets gamification
run freely without every reward touching money. Kids can spend F$ on
in-app rewards (screen time, choose dinner) with zero parent friction,
and on real-world things via an approval flow.

**Alternatives considered:** Single currency (conflates game and money,
creates friction); pure real-money allowance (no gamification layer,
high friction for small rewards).

**Do not revisit unless:** Core allowance product direction changes
fundamentally.
