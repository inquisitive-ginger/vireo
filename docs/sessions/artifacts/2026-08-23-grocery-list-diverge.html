What goes on a grocery row

Navigation is decided. What's left is what the row says and what happens while you type — now rendered inside the settled structure rather than against a generic list.

Settled

Structure
Each store is its own list. Home is an index of lists; tap to enter one full-screen.
Empty lists
Permanent lists (Grocery, Costco) stay visible and dim at zero. Runtime lists appear when they have items.
Creating
Tier 4 makes lists. Anyone who can add an item can add to an existing one.
Grouping
Aisle, inside a store — where aisle order is walk order. Not universal: a future non-food list won't have aisles.
Adding
Inside a list the destination is implied. Only the index needs "Add to…".

What happens while you type

The pills felt crude because they were equal-weight buttons with no stated relationship to what you typed. Three ways out, all inside a store list where the destination is already known.

S1Inline completion

The field completes ahead of the cursor in muted text. Nothing appears and nothing moves — no layout shift, no second target, no thumb travel. Fastest for a word you've typed a hundred times, silent for anything new.
