M4/9 · XP sink · design direction v1

The Companion

XP has been minting since M2 with nowhere to live. It becomes a critter — hatched by each kid, grown by the XP they earn, dressed by the choices they make at milestones. P$ buys things; XP grows something. The feature name is decided at the dinner table — mocks below use the working register “critter.”

Three species, kid-tested — Whisp (a dreamy floater), Skitter (a six-legged monster, spider-like but never creepy), and Sprout (a leafy seedling). The species sets the character; gear makes it yours — a Skitter with a drum kit is a rockstar, a Sprout on a skateboard is a daredevil. The color is the kid's identity hue — in every family view the critter reads as its kid by shape and color.

Production art is a build-time generated library (style bible + curation gate + duotone-to-hue pipeline); the critters on this page are parametric-SVG stand-ins for silhouette, proportion, and gear anchoring.

03 · The three tempers

Widget states — ambient, never demanding

Mood is derived from the XP balance's own timestamps — no stored state, no decay mechanic, nothing to feed. Perky after a day with XP, resting after a quiet stretch. The milestone-ready state is the only one that asks for a tap, and it arrives with a notification.

08 · What this artifact commits to

Decisions embedded above

OwnershipNew companion plugin (family-feed structure). Reads XP server-side via @family-os/plugin-chores/db; subscribes to chores.task.completed for threshold detection. Never touches the rewards ledger.
XP is untouchedOne up-only integer, never spent, never debited. Levels are a pure function of XP earned since hatch. ScorePlate, XpPill, the flight — all unchanged.
IdentitySpecies = the kid's choice (Whisp · Skitter · Sprout, kid-tested 2026-08-06); color = their identity hue via the duotone pipeline. The species sets the character; gear makes it yours — any species can be a rockstar or a skater.
ADR 042 holdsGear renders on the critter only. The avatar, the photo, and every existing identity surface are untouched — no amendment needed.
Quiet-star register holdsXP keeps its muted star everywhere. The meter fills in the kid's hue — never brass, never gold (ADR 051/054 undisturbed).
MoodDerived at read time from XP recency. Perky · resting — never sick, sad, or punitive. No care loop, no decay, nothing lost on vacation.
Gear taxonomyV1 ships worn (head/face/neck) and props (held/beside — the personality half). Scenes (backdrops) are a later content drop on the same pipeline. Gear pigments stay clear of identity hues, brass, and error red at UI distance.
Art pipelineBuild-time generated library: an image model generates bodies (3 species × 3 stages × 2 moods, neutral grayscale) and gear layers against a locked style bible + anchor spec; every batch is human-curated before it ships as static plugin assets. Runtime composites layers and duotone-maps bodies to the kid's hue triplet. The Pi never calls a generation API.
Style bibleSticker-flat/cel: flat tonal regions, confident outline, minimal shading — the style the duotone constraint selects, and the one that survives 100px widget size. This page's SVGs are silhouette/anchor stand-ins for the generated art.
Custom gear (designed-for)A later tier-4 surface: a parent types "a hat for soccer season", the server generates candidates inside the style guardrails, the parent approves one into the milestone pool. Rare, human-gated, online-only, degrades gracefully — generation never sits in the kid loop.
NamingFeature name decided at the dinner table. Each kid names their own critter at hatch; the name is permanent.
