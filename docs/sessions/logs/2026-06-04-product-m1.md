# Session Log — M1 Product Planning

**Date:** 2026-06-04
**Type:** Product

## What was decided

### Form library: React Hook Form + Zod

Settled for all stories with forms (family-onboarding, profile-management, family-feed-compose). Zod schemas shared between client and server via `packages/schemas` (new package, scaffolded in family-onboarding). Plugin-local schemas (family-feed-compose) stay within the plugin.

### Component library convention

New UI components introduced by each story are added to `packages/ui` with Storybook stories before the implementation session closes. No dedicated ui-foundations story — components are built in the context they're first used.

### Dark mode toggle scope

Available to all tiers (not tier 4 only) — it is a display preference, not a management function. The family pseudo-profile follows `prefers-color-scheme`.

### Web Push opt-in storage

`push_enabled boolean default false` on the `profiles` table. Per-profile attribute, not a system_config key.

### family-feed.post.create tier baseline

Tier 2+ by default. Tier 1 is read-only. Parents can grant to tier 1 via permission-overrides.
