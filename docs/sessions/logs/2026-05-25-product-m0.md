## What Was Decided

- **M0 broken into 6 stories** (see below). All traceable to the M0 done definition: *a plugin can be installed and rendered on the tablet.*
- **Monorepo tooling settled:** pnpm workspaces + Turborepo (ADR 016). Not previously decided; resolved in this session to unblock the dev-environment story spec.
- **Bulletin board deferred to M1+.** It requires a complete plugin system and its communication model is better defined alongside the first real module (chores). Not required for M0.
- **Login/profile-switch UX is not designed in M0.** Auth story owns the infrastructure (hooks, gates, profile data) but explicitly defers the UX mechanism. A dedicated design session is queued.
- **Product session template created** at `docs/sessions/templates/product.md`.

## Open Questions Raised

- **Login / profile-switch UX** — what does it actually look like on the tablet? A switcher screen? PIN entry? QR? Something else? Flagged as a new design session in the queue (must complete before auth-and-profiles implementation).
- **Auth identity mechanism** — JWT vs. Lucia vs. session cookies. Still deferred to M0 Architecture session. Auth story ACs are written to be mechanism-agnostic.
- **Platform API surface** — the full typed SDK contract for `@family-os/platform`. Deferred to M0 Architecture. Plugin Loader and Demo Plugin stories call out the subset they need.

## What the Next Session Needs to Know

- M0 Architecture is up next. It should read the story specs before starting — several stories have explicit notes about what architecture must resolve.
- Auth-and-profiles story is blocked until M0 Architecture settles the identity mechanism.
- The permission string registry must be defined before auth-and-profiles or plugin-loader can be fully implemented.
- Plugin dev toolchain / scaffold (how a plugin author sets up a new plugin) is on the M0 Architecture scope — it wasn't addressed in any story spec.
- ADR 016 (monorepo tooling) was written in this session — read it before proposing any build pipeline decisions.
