## #112 — six tabs on a phone

Meals shipping pushed the bottom bar to six `flex-1` tabs (Home + five plugin
tabs) — past ADR 033's own overflow trigger ("do not revisit unless core module
count exceeds 4"). Gated options (bottom sheet vs anchored popover; pin
mechanism): **bottom sheet** won, pinning by registry order.

- `BottomTabBar` caps at **5 tabs**: Home, the first three tier-visible plugin
  tabs, and a **More** tab opening a `Sheet` listing the rest. More carries
  active state when an overflowed route is current; no overflow → no More tab.
  Tier filter applies before the cap, so a tier that sees ≤4 items never gets
  More.
- `plugins.json` reorders meals ahead of rewards so the pinned three are
  Calendar · Chores · Meals (Dad's ask). Side effect accepted at the gate: the
  desktop sidebar order changes to match.
- ADR 033 addendum records the early trigger; the pinning **management UI**
  stays deferred to M8+.
