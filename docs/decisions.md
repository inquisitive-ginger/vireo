## D-075 · 2026-11-14 · A maintainer token moves bug-report status

`PATCH /bug-reports/:id` needs a tier-4 PIN session, so `issues.onStatus` can't run from a script. The API accepts a bearer token from an env var that grants only that route, so a fix's status, and the reporter's "Fixed — live" notification, flows from `/lock-in`. Until it ships, flip reports by hand in Settings → Reported problems.
Options: build the token before adopting Throughline; adopt first and flip by hand meanwhile (chosen). Features: F-008. Approved: Zach, in the adoption planning.
